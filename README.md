# Custom Profile Card 🎨

A responsive profile card UI built using HTML and CSS. The project focuses on creating a clean and modern card design with animations, styling, and social media integration.

## 📌 Features

- Modern profile card design
- Gradient background
- Circular profile image
- Social media icons integration
- Smooth card entrance animation
- Responsive layout for different screen sizes

## 🛠️ Tech Stack

- HTML5
- CSS3
- Font Awesome Icons
